# Escrita Técnica para IA
Skill para IA escrever textos técnicos de forma clara e objetiva

## Instalação
Carregue SKILL.MD na plataforma de IA desejada
Adicione nas instruções de sistema:
> Use a skill `escrita_tecnica` quando for escrever qualquer texto técnico. Não usar para texto criativo.

## Teste
1. Peça para IA escrever um artigo científico, relatório técnico, documentação de código etc;
2. Teste com e sem a skill;
3. Verifique se o texto ficou mais claro e sem frases de efeito usando `escrita_tecnica`.
